# Multi-Vendor B2B E-Commerce Platform (BizHub)

Full-stack Multi-Vendor B2B E-Commerce web application built with React/Vite (frontend) and Node.js/Express/MongoDB (backend), configured for deployment on Vercel.

## Structure
- `frontend/` - React + Vite application
- `backend/` - Node.js + Express API server (Mongoose serverless-ready)
- `DEPLOYMENT_GUIDE.md` - Deployment instructions for Vercel and MongoDB Atlas

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
